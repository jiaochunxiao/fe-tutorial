# 前端进阶之路 · 专题博客课程体系

> 一套面向前端开发者的循序渐进式学习课程，风格对标「冴羽的博客」深入系列：**例子先行、由浅入深、剖析原理、图解辅助、面向面试**。
> 定位：为「前端面试刷题助手 上岸offer」小程序提供体系化的专题博客内容。

## 一、目录结构

```
frontend-mastery/
├── README.md                 # 本文件：使用说明 + 写作规范
├── roadmap.md                # 课程学习路线总纲（三阶段 / 全部篇目）
├── _template.md              # 单篇文章的标准模板
├── p1-foundation/            # 第一阶段 · 初级：夯实基础
├── p2-intermediate/          # 第二阶段 · 中级：知识进阶
└── p3-expert/                # 第三阶段 · 高级：高级进阶
```

每个阶段下按「系列」组织目录（系列 id 与 roadmap.md 一致），例如：

```
p1-foundation/javascript-deep/js-deep-005-closure.md
p2-intermediate/async/js-async-005-event-loop.md
p3-expert/v8/v8-005-memory-and-gc.md
```

## 二、文章元信息（小程序录入约定）

每篇文章以 YAML frontmatter 开头，字段含义：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 全局唯一，`系列id-三位序号`，如 `js-deep-005` |
| title | string | 文章标题（建议「XX系列之XXX」句式） |
| series | string | 所属系列中文名 |
| seriesId | string | 所属系列 id |
| stage | string | `foundation` / `intermediate` / `expert` |
| difficulty | number | 1~5，对应初级~专家 |
| tags | string[] | 标签，可直接映射小程序标签体系 |
| readingTime | number | 预计阅读分钟数 |
| prev / next | string | 同系列上/下一篇 id，用于串联阅读路径 |
| createdAt | date | 创建日期 |

**与刷题产品的联动**：每篇文章末尾的「思考题」章节可直接转化为题库的关联题目，建议在小程序内做「读完即练」的入口。

## 三、写作风格指南（所有文章统一遵守）

1. **例子先行**：用一段可运行的代码或一个真实场景开篇，先制造疑问，再展开原理。
2. **由浅入深**：现象 → 直觉解释 → 规范/引擎层面的严谨解释，三级递进。
3. **代码即文档**：所有代码必须可运行、带注释，标注「关键输出」。
4. **图解辅助**：内存结构、执行流程类内容必须配 ASCII 图或示意说明。
5. **规范有出处**：涉及语言行为时引用 ECMAScript 规范、HTML Standard 或 V8 官方资料，注明条目。
6. **口语化但不失严谨**：允许轻松的比喻，但结论必须精确。
7. **固定收尾结构**：总结（可背诵版结论）→ 思考题（3~4 题）→ 参考文献。
8. **面试视角**：在关键节点标注「⭐ 面试高频」，总结给出「面试一句话回答」。
9. **篇幅**：单篇正文 3000~6000 字 + 代码，阅读时长 12~25 分钟。
