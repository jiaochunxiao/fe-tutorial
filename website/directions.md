# 方向卡（六候选）

> 轮盘随机数：S=28 → web 分区 28%20+1=**9 号 像素游戏横版**；east 分区 28%12+1=**5 号 中文实验字体海报**。

## 候选 1 · 最佳设计师｜Experimental Jetset——「知识即系统」

- **逻辑与来源**：阿姆斯特丹三人组 Experimental Jetset，把内容本身当版式系统的谱系（大量使用清单、编号、索引）。
- **借的是什么**：等宽栏网格、清单即界面（19 个系列的可勾选目录就是主视觉）、系统字+等宽标签、蓝链接、发丝分割线、几乎零装饰。
- **主角素材**：数据图像——19 系列的编号/篇数/时长清单本身；无图。
- **骨架**：单栏长清单 + 顶部大字标题带，编号系统贯穿全页。
- **胆量花在哪**：首屏一整面「学习清单」当英雄——列表即 hero。
- **form 来自内容的哪里**：一门「体系化」课程，界面本身就是一份可勾选的目录。

## 候选 2 · 最佳设计师｜吕敬人——「书页上的课程」

- **逻辑与来源**：吕敬人（书籍设计，「书衣大师」，《中国记忆》获世界最美的书荣誉奖）。
- **借的是什么**：版心呼吸（版心上提靠订口、天头小地脚大）、朱砂红只用一处、章节扉页大字+大量留白、旁注栏放注释、行距 2 以上。
- **主角素材**：排印本身 + 课程真实原理图（js-deep-005 闭包的环境引用图）+ 一个大字。
- **骨架**：阅读优先的书页单栏流 + 扉页式大字开场。
- **胆量花在哪**：首屏一个巨字「进」配一行小注，其余全留白。
- **form 来自内容的哪里**：158 篇是一本书，阅读页就是书页——长文阅读体验是本站的核心资产。

## 候选 3 · 现实参照｜Tailwind CSS Docs——「彩虹分类文档」

- **逻辑与来源**：tailwindcss.com/docs（参考板 refs/board-1.jpg，已亲眼看过）；风格库 web15「实用主义彩虹分类文档」同款。
- **借的是什么**：三栏文档骨架（侧栏目录/正文/TOC）、分类色标（每个系列一个色相）、编号步骤条、暗色代码块、清爽正文。
- **主角素材**：真实文章结构 + 真实代码块（闭包篇片段）。
- **骨架**：文档三栏 + 彩虹系列分类卡。
- **胆量花在哪**：19 个系列各占一个色相的彩虹分类系统。
- **form 来自内容的哪里**：158 篇技术文档，用户需要「查得到」的秩序。

## 候选 4 · 现实参照｜roadmap.sh——「路径即品牌」⭐

- **逻辑与来源**：roadmap.sh/frontend（参考板 refs/board-2.jpg，已亲眼看过）——开发者学习路径站的事实标准。
- **借的是什么**：大标题+一句副标题的开场、彩色节点+虚线连接的路径图（节点=可点击单元）、进度追踪语义、深色导航头、按路线筛选。
- **主角素材**：学习路径图——P1/P2/P3 三段路径，19 系列作为路径上的节点。
- **骨架**：路径图为主体（首屏即一张「进阶之路」）。
- **胆量花在哪**：把整条学习路径画成首屏主角。
- **form 来自内容的哪里**：站名就叫「进阶之路」——路径图即品牌本身。

## 候选 5 · 秒数轮盘｜web09 像素游戏横版——「闯关式学习」

- **逻辑与来源**：轮盘抽中 web 分区 9 号（样张 assets/style-specimens/web/09-pixel-side-scroller.jpg 已看过；还原度 70%，像素插画无生图降级为 CSS 方块拼贴）。
- **借的是什么**：分关卡换色（每阶段一个色世界）、HUD 状态栏（进度/篇数/时长）、关卡式推进、像素图标。
- **主角素材**：CSS 方块拼的像素场景与图标（诚实降级标注）。
- **骨架**：横版三关卡 = P1/P2/P3 三个色世界，横向滚动推进。
- **胆量花在哪**：整站做成「闯关地图」——⚠️ 用力过头候选，三张里最多选它一张。
- **form 来自内容的哪里**：刷题与晋级本来就是「闯关」。
