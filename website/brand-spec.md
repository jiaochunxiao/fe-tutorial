# Brand Spec —— 《前端进阶之路》

## 品牌本身

- 站名：前端进阶之路；副品牌：上岸offer（作者的小程序名）
- **无既有 logo / VI**（个人项目）→ 文字 wordmark + 系列图标系统承担品牌识别，三方向各自诠释
- 出现「Vue / React / TypeScript」等第三方技术名称时，使用官方图形（simple-icons，CC0），不手绘仿冒
