02 / 讲义摘录

本周精读

不用一次读完 158 篇。先把一个机制真正讲透。

精读 05｜18 分钟

JavaScript 深入之
闭包

面试高频，作用域链与内存管理

从一段 for + setTimeout 的输出题切入，用 [[Environment]] 内部槽讲清闭包的机制本质，再走到内存代价与四类真实应用。

阅读这篇讲义↗
闭包机制JavaScript
function foo() {
  var a = 2;
  function bar() { console.log(a); }
  return bar;
}

const baz = foo();
// foo 已出栈，但 a 仍被
// [[Environment]] 引用，无法回收。

真正要记住的不是定义，而是：函数在哪里创建，就记住了哪里的词法环境。
